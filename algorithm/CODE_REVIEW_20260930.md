## 檢查依據

以對話中的五模型、先模擬後外部驗證、主要事件分類及輔助回歸為主。原 PDF 不在指定路徑，沒有宣稱逐頁核對原稿。可執行規格已整理為 [RESEARCH_PROTOCOL.md](RESEARCH_PROTOCOL.md)。

## 修正與補齊

| 發現 | 處理 |
|---|---|
| 原有程式僅生成器與部分指標，不足以完成整個研究 | 補齊五模型、共同訓練、調參、事件評估、規則學習、外部輸入與報告輸出 |
| 參數變動會消耗不同亂數，干擾情境配對 | 圖、權重、觀測、特徵及反應分離亂數流；加 burn-in |
| 邊替換率分母多計一倍 | 改成真正的既有邊替換比例，保存 realized drift |
| 未有一致時間留出與預測窗邊界保障 | 訓練／驗證／測試順序切分，purge 越界標籤窗 |
| 圖與資料預處理可能偷看未來 | 固定校準窗與 trailing graph；只用訓練 scaler、中位數，保留缺測 mask |
| 缺測小時 resample 產生 NaN mask，真實資料試跑會中斷 | 明確轉成 boolean mask；跨長時間缺口重置感測器平值計數 |
| 事件與回歸若共用小時最後值，可能漏掉小時內尖峰 | 事件用小時 peak、回歸用小時 last；persistence 採同一事件定義 |
| 將同一事件的重複警報混作不同成功案例 | onset 前一對一配對；重複、事件外警報、censored 事件分列 |
| bootstrap 把缺测刪列後的不同時段當相鄰 | 時間區塊遇 origin 間隙停止，不做 IID node/time bootstrap |
| selector 的候選樣本可能依測試 AP 是否存在決定 | 擬合樣本僅依 validation 完整性；測試只作評估 |
| η 變體與 λ=0 無效變體可落在規則訓練與留出兩側 | 使用生成機制分組，並去掉 estimated arm 的完全等價工作 |
| 外部資料可能重新擬合選擇規則 | 只載入已凍結模擬規則，另存 transfer_evaluation；超範圍或缺失時拒絕單選 |
| 計算中斷可能留下錯誤的完成狀態 | 模型 result marker 最後寫入；報告完成才標記 complete；批次保存狀態、日誌與鎖檔 |
| 續跑可能混入不同程式或資料 | 設定、程式、資料內容 checksum 檢查；背景使用獨立程式快照 |
| 政府 API export 可能只回傳前 100,000 筆 | 改用 page/size、重複頁檢查及 gzip SHA-256，當次取得 427,373 筆 |
| 缺少實測完整歷史及同期上游資料 | 自動產生資料不足報告，不宣稱完成外部驗證 |

## 驗證結果

- 38 項測試：圖不變量、生成器重現、GCN 數值、GAT mask／softmax、五模型梯度與 permutation、MLP 鄰居隔離、時間洩漏、延遲資料、品質缺測、事件配對、案例圖表、規則分組及下載封存。
- 最終模擬整合測試：3 情境 × 1 seed × 3 horizons × 5 模型，共 45 工作，全部完成並產生 HTML、PNG、CSV、JSON、weights 及 predictions。
- 真實資料處理可完成；固定 τ=1000 NTU 時，驗證／測試均無正例，故模型比較正確標示 insufficient_data，而不是產生排名。
- 小規模結果只證明流程可執行。三個有效生成情境不足以擬合規則時，規則檔明確回報 insufficient_scenarios；第一輪 21 情境批次才評估規則。
- 最新資料指紋修正另以封存續讀測試確認，不因 last_checked_at 改變而誤判資料內容變動。

完整第一輪為 945 模型工作／1890 候選 fits，背景執行紀錄在 `results/overnight_20260930/`。此文件不把啟動批次寫成完成批次。
